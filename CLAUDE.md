# Instrucciones para asistentes de IA

- Puertos fijos del proyecto: ver [docs/puertos.md](docs/puertos.md). No cambies puertos para esquivar un `EADDRINUSE`; libéralo con `npm run puertos:liberar`.
- La demo con 15 empresas y 450 productos se ve en http://localhost:3300; el 4200 muestra la base de desarrollo.
